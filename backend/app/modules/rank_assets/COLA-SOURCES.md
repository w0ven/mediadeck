# COLA EMBY poster assets

`cola-landscape.jpg` is a locally resized decorative landscape, sourced from:
https://images.unsplash.com/photo-1470770841072-f978cf4d019e

Unsplash license: https://unsplash.com/license

Poster rendering does not fetch this photograph at runtime. Film and series
art is obtained through the configured Emby connection for the actual chart.
No demonstration lineup, viewing counts or rank changes are bundled in the
production renderer. The existing bundled CJK font is reused.
