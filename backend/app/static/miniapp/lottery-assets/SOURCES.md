# Lottery emoji artwork

17 original Telegram static images/thumbnails from the approved Lucky Studio
preview, not redrawn replacements. Used only in lottery Mini App screens.
The corresponding Bot messages use native Telegram custom emoji entities and
button icon IDs, never HTML image tags. No preview participants or results are
included in these assets.

- [Colorful Font Emoji](https://t.me/addemoji/ColorfulFontEmoji): `L`, `U`, `C`, `K`, `Y` (pack indices 11, 20, 2, 10, 24).
- [ZaiHuaNews](https://t.me/addemoji/ZaiHuaNews): `starCute` (42), `rocket` (118), `gift` (190).
- [Mix Emoji / IslomjonAnimeEmoji](https://t.me/addemoji/IslomjonAnimeEmoji): `star` (0), `verified` (1), `shield` (40), `giftPurple` (136), `gem` (156), `megaphone` (160), `giftBlue` (166), `giftPink` (168), `party` (169).

These are source-pack artwork, not MediaDeck artwork; original authors retain
their rights. The static frames do not simulate the packs' original animations.
