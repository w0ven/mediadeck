## 核心修复

### 账号、TG 与权益
- 注册资格、名额、卡密、绑定、成员写入与消费保持事务一致；设置密码失败、并发抢码、取消创建不再误报成功或留下已知可清理的裸账号。
- 签到/转账日限额/邀请铸码、默认组切换、重新绑定、商城扣分与有效权益授予原子化，失败回滚，不为无效权益收费。
- 管理员权限、成员身份、审核群与删除对象在异步等待后复核；使用原始确认范围，失败不会显示“已删除”。
- 自动策略用专用安全适配器，在最近的单用户 Emby 读取后拒绝自动修改管理员；手动管理 API 语义保持。
- Web/TG 改密成功立即清登录正缓存；TG 换组/续期/商城/赠送接入主应用权益联动，仅有效限速变更才重签和结束旧播放，其他即时执行遵守现有 enforcement 开关。
- 远端失败明确显示本地成功、远端未确认，不撤回已完成订单、不二次消费。

### 播放、统计、计量与安装
- 日志字节与游标同事务提交，HTTP 重试去重，普通重命名/copytruncate 路径有回归；旧多段不推进游标的 reporter 需与 API 协同升级。
- flowmeter 重启不重复追加计数规则；连接复用、旧身份结算、最终字节 ACK 不再混归或提前回收活动元素。
- 探针 `/announce` 限实际 loopback 对端；IPv6、过期归属、缺失采样及跨节点部分覆盖正确区分未知与真零。
- 显式 MediaSourceId 不存在时不擅自选择另一版本；访问授权校验精确目标 ID；缓存取消能释放等待者；切 Emby 源清缓存且海报按 origin 隔离。
- 总览采用个人有效配额/计费模式，实测切换后读实测账本而非旧估算；暂停/空闲不参与正在共享判断，历史观看导入保留不重叠边界。
- 安装输出按 shell/systemd/nginx 各自语法引用，opaque heredoc 使用不冲突结束标志；先 HTTP 获取证书再生成 TLS 站点，补必要依赖。仅渲染与语法检查，未执行安装。

### 运维、持久化与后台
- 设置写盘失败不发布内存修改；已有坏/无权限文件不再被当成首启而覆盖。
- 配置 URL、类型、非有限值、secret sentinel 正确校验；字符串 `false` 不再误开开关。
- 存储文件私有原子写，拒绝配置/单元注入、stop 失败不删 unit、失败不泄漏上游敏感内容。
- 失败通知不启动停用宽限期；批量投递重试保留已确认进度；插件恢复日程、失败可重试、取消释放锁，慢 topic/插件不拖停其它任务。
- 更新/存储/快照阻塞调用移出事件循环，存储 worker 保留串行读改写；退出等待采样、插件和 Bot 后再关 DB。
- 无执行器的 live import 明确拒绝，不再返回永远 queued 的假成功；自更新拒绝脏树/重复助手且不强制 checkout。

### Web 全站
- 迟到 loader/操作回包不覆盖新页、不重开旧详情、不清新草稿；保存一项不清其它草稿。
- 多类表单在途防双击、失败恢复输入；插件运行读取真实可见配置，卡密筛选、完整邀请成员列表可用。
- 权限编辑原值 round-trip 保持字节/带宽/时间精度；媒体库或挂载列表失败不清掉未展示的既有分配。
- 修复内联 JavaScript 参数注入；弹窗/抽屉/移动菜单命名、焦点、inert、滚动及键盘操作；媒体根删除有明确取消入口。
- 所有节点速率统一过期处理，未来时间无效；HTTP 失败不再伪装空数据。

## 发布阻塞：v1 签名协议

v1对 `expires + decoded_uri + r + u + ' ' + secret` 直接拼接后认证，变长字段边界可被重新拆分，已在本地证明限速/计量身份可以改变但签名仍有效。**没有检查真实用户链接，也没有证据证明已被利用。** 固定用户标签宽度只能缓解一部分，不能修复全部字段边界。

复现保留为：

```text
tests/test_audit_streaming_regressions.py::test_signed_rate_and_identity_fields_cannot_be_repartitioned
```

推荐专门安排无歧义、版本化 MAC 协议迁移：
1. 先使所有节点正确支持v2，再由面板只签发v2，禁止给旧节点下发不兼容链接。
2. 渐进方案可暂容v1至既发链接最长寿命结束，但漏洞窗口持续到所有节点停止接收v1；配置最长可到7天。
3. 更强的立即切换方案同时拒绝v1并失效旧密钥，需明确接受已有链接重签/播放中断及既有连接处理。

**本轮未代替用户决定这一兼容/中断取舍，没有切协议、轮换密钥或部署。** 不能直接将此分支作为“已完全安全”的版本发布。
