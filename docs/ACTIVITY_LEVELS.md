# 观影等级与活跃保号：验收、迁移与回滚

## 状态与授权边界

本功能只完成本地开发与隔离验收，不表示已上线。代码、数据库增量结构、任务注册与开启业务是不同步骤。发布、部署、服务重启、生产迁移、生产扣费及启用真实删除均需另行授权。

默认关闭：

- 等级配置 `enabled=false`、`delete_enabled=false`。
- `watch_rewards`、`activity_lifecycle` 定时插件默认未启用。
- 观影结算还需 `watch_rewards.activate_rewards=true`；首次运行才写不可回退的奖励起点。
- 签到插件 `dual_checkin=false`；旧逻辑保留以支持受控切换，同日已按旧规则签到者不会重新领新奖励。
- 用户 `auto_renew=false`，必须由本人主动开启。

## 运行入口

- 管理后台「等级与权益」：编辑图标/短名/称号、成长门槛、价格和基础额度，预览/确认迁移，查看删除候选。旧组在默认折叠的兼容维护区，白名单及个人/道具权益保留。
- 成员详情：查看等级与最终有效权益，管理员明确授予专属Lv8；删除结果不明时可核实远端存在后恢复删除互斥。
- Bot：`/activity`、`/renew30`、`/autorenew_on`、`/autorenew_off`；`/checkin` / 签到与 `/luckcheckin` / 运气签到共用同一状态机。
- 成员Web：Bot私聊 `/webaccount` 生成5分钟一次性登录码，在面板同源 `/activity` 登录。登录会话最长1小时，换绑后立即失效，管理员身份不能冒充成员。账号到期仍可查看和达标续费。
- 管理API：`/api/activity/config`、`/api/activity/migration`、`/api/activity/deletion-preview`；成员API：`/api/activity/me`、`checkin`、`renew`、`auto-renew`。预览和GET不结算奖励、不迁移、不删除。

静默结算每60秒运行；等级变动、到期与续费权益通过现有成员有效权益/播放准入路径生效，并由现有策略同步循环补发远端策略。远端策略写入仍服从现有 enforcement 开关，未获确认不会显示远端成功。无需用户打开页面触发奖励或升级。

## 核心不变量

- 北京时间每日：前20分钟每满5分钟8积分/5成长，之后至60分钟每满5分钟2积分/5成长；每日48/60封顶。多设备区间合并，跨午夜拆分；持久化待结算证据、并集和日水位与积分/成长原子提交，重试/重启不重复发奖。
- 积分与成长独立。普通自然等级Lv1～Lv7；Lv8「道祖 / 一炁化三清」只允许迁移或管理员授予，基础额度默认同Lv7、续30天1积分，不因成长自动获得或降级。
- 续费近30天核验至少4800秒、至少3个各满600秒的北京时间日；手动在到期前72小时内、自动在前24小时内检查。只续30天，不重置月用量、求片、人工禁用或个人覆盖。余额扣款、期限、回执原子提交。
- 普通签到最终10；运气最终1～30，区间概率65%/25%/10%，段内整数等概率，期望10。普通→运气只调整差额，运气为终态；抽签前检查最多回收9积分的可用余额，已冻结资金不可使用。取消旧积分加成但保留一次连签/活动掉落。
- 已有/未来白名单销售和永久卡保留原豁免；有效限时白名单卡继续优先。等级基础先投影，再叠个人覆盖及有效带宽/同播卡，下载、转码、媒体库权限不凭等级扩大。
- 普通等级用户不再由旧不活跃清理提前停用。到期禁止播放，72小时保留期间只读与达标续费；新购买/道具使用受限。删除前复核期限、豁免、临时卡、人工状态、远端非管理员身份与未结算资金/观影证据。
- 删除持久化互斥阻断续费/改资格/新消费，远端失败保留本地账号与账本。重试需重新确认远端；明确404且本地授权仍有效可完成已删除账号的本地收尾。不会连坐邀请人，不级联抹去积分、成长、背包、订单和审计；成员/设备绑定移除后旧登录码无法使用。

## 一次性迁移规则与操作顺序

以下为之后获得授权时的操作说明，不是本次已执行操作。

1. 按正常发布流程部署已通过CI的版本前，备份数据库与持久化配置；在隔离副本验证还原。公开源码/报告不得携带实际账号名单和凭据。
2. 先保持等级与所有新任务关闭，读取管理迁移预览。窗口固定为北京时间2026-10-01 00:00至预览时刻。
3. 有可靠 `watch_verified_since` 时优先采用，否则使用首条实际核验证据；无法确定切点则拒绝。切点前仅本次分类采用有日期旧 `watch_samples`，切点后只采用 `watch_verified_samples`。逐用户区间去重、跨北京时间日拆分。预览显示切点、来源、旧/核验各自秒数；没有记录不补造，不声称旧证据等同严格核验。
4. 严格大于6000秒且至少4个各满600秒的观看日授Lv8；其余Lv1/成长0。不追发历史观影积分、不按历史签到补成长。所有普通老账号无论余额统一免费30天，从同一预览时刻起算；白名单豁免。人工禁用保留；未开通、明确更长期限/永久个人覆盖等列异常，不偷偷缩短。
5. 复核异常后，用预览的 `hash`、`as_of`、唯一 `request_id` 与 `confirm=true` 提交；预览限10分钟。账号、权益、余额或证据变化会拒绝陈旧预览。相同请求重试返回原回执，再次预览已迁移者不会重复赠送天数。
6. 核对迁移结果、期望等级/日期、旧余额与背包不变，才启用等级配置及所需插件。签到切换与观影奖励各自显式开启；观影奖励不会回填开启前记录。先用删除候选预览观察，`delete_enabled` 继续关闭。
7. 真实删除启用必须再次单独获准。不要把「启用生命周期提醒/自动保号」等同于「启用删除」。

## 失败恢复与回滚

- 观影批次失败整体回滚；保留待结算记录，恢复任务后继续。关闭结算仅暂停发放，恢复会补结原生效点之后积压的核验证据；不是重置奖励起点。
- 续费响应丢失以同一请求ID重试，不再扣款；远端同步失败不撤销已经成功的本地续费，由同步循环重试，不虚构远端成功。
- 删除失败/超时保持互斥，不先清账。任务重试时重新检查远端与本地；管理员恢复入口只在租约结束且远端账号仍存在时解除互斥，不修改到期日期、不解人工禁用。删除未确认前不要手工改账或强行重新开户。
- 切换前回滚：关闭所有新开关即可保持原行为；增量空表可保留，不要为回滚主动删除表、账本或水位。
- 已迁移或产生新业务后的回滚：**仅切回旧代码或关闭等级不是数据逆迁移**。先停止相关业务写入并保存当前快照与回执，评估需要保留的新积分/消费/续费，再由获授权维护窗口按预先验证的数据库及配置备份恢复，或逐项审计修正。禁用新等级期间旧不活跃插件可能恢复命中这些账号，必须纳入回滚检查。
- 已确认删除的远端账号不能靠撤销本地标记复活；需单独人工恢复授权。未提供危险的自动逆迁移/自动重建账号命令。
